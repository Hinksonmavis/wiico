## About

WIICO is an enterprise-grade platform designed to manage digital
advertising operations, membership programs, referral networks,
commission distribution, and financial activities within a unified
ecosystem.

The platform provides dedicated experiences for members and
administrators, enabling secure account management, membership
operations, referral tracking, wallet management, transactions,
advertising activities, and administrative oversight.
